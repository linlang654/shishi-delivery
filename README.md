# 事事洗护配送网页系统 部署刷新

这是一个纯静态网页/PWA 原型，不需要后端即可使用。订单批次、配送状态和异常备注会保存在当前浏览器本地。

## 使用

直接打开 `index.html` 可以使用；更推荐用本地服务器打开：

```powershell
cd "C:\Users\毛文峰\Documents\New project 2\web-app"
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

手机访问时，需要把网页部署到公网，或放到同一网络可访问的服务器。部署到任意静态网站服务即可。
